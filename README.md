# Практическая работа: Windows Forms (C#)

Учебный проект с формой выбора задания и набором небольших программ на Windows Forms.

## Что нужно для запуска

- Windows 10 или 11
- Visual Studio 2022 с компонентом **«Разработка классических приложений .NET»**
- .NET 8 (устанавливается вместе с Visual Studio)

## Как открыть и запустить

1. Распакуйте архив `WinFormsPractice.zip` (правой кнопкой → **Извлечь всё**). Не открывайте файлы прямо из архива.
2. В Visual Studio выберите **Файл → Открыть → Проект или решение**.
3. Выберите файл `WinFormsPractice.csproj`.
4. Нажмите **F5** (или зелёную кнопку «Пуск»).

Откроется окно «Выбор задания». Кнопка открывает окно нужного задания.

## Структура проекта

| Файл | Что делает |
| `Program.cs` | Точка входа, запускает главную форму |
| `MainForm.cs` | Главная форма с кнопками выбора задания |
| `Task1Form.cs` | Задание 1: игра «Угадай число» |
| `Task2Form.cs` | Задание 2: кнопка «случайный цвет» меняет фон формы |
| `Task3Form.cs` | Задание 3: TextBox и кнопка «отобразить», текст показывается в MessageBox |
| `Task4Form.cs` | Задание 4: текст на нажатой кнопке берётся из поля ввода |
| `Task5Form.cs` | Задание 5: кнопки показывают скрытые метки (свойство `Visible`) |
| `Task6Form.cs` | Задание 6: кнопки «блокировать» и «разблокировать» поле ввода (`Enabled`) |
| `Task8Var2Form.cs` | Задание 8, вариант 2: калькулятор с кнопками 0–9 |
| `WinFormsPractice.csproj` | Файл проекта |

## Как пользоваться заданиями

**Задание 1: Угадай число.** Программа загадывает число от 1 до 100. Введите число и нажмите «угадать!». Появится подсказка «число больше» или «число меньше», а также счётчик попыток. Кнопка «заново» начинает игру сначала.

**Задание 2: Случайный цвет.** Каждое нажатие задаёт фону формы случайный цвет по модели RGB.

**Задание 3: MessageBox.** Введите текст и нажмите «отобразить», текст появится в окне сообщения.

**Задание 4: Текст на кнопке.** Введите текст в поле и нажмите на любую из кнопок, её надпись изменится на введённый текст.

**Задание 5: Скрытые метки.** При открытии формы все метки скрыты. Каждая кнопка показывает свою метку.

**Задание 6: Блокировка поля.** «блокировать» делает поле неактивным, «разблокировать» возвращает его в рабочее состояние.

**Задание 8: Калькулятор.**
- Числа и действия вводятся кнопками, выражение записывается в одну строку, например `18*2`.
- Кнопка `=` считает результат, `Стереть` удаляет последний символ.
- Используется тип `double`, поэтому поддерживаются дробные числа (кнопка `.`).
- Деление на 0 и некорректное выражение обрабатываются: появляется сообщение об ошибке.

## Если что-то не работает

| Проблема | Что делать |
| Сообщение «Исполняемый файл для отладки не существует» | Проект не собрался. Откройте вкладку **Список ошибок** внизу и посмотрите первую ошибку |
| Много ошибок `CS1056: Недопустимый символ "\0"` | Файлы повреждены. Заново распакуйте архив в новую папку и откройте проект снова |
| Нет нужного компонента Visual Studio | Запустите **Visual Studio Installer** → «Изменить» → отметьте «Разработка классических приложений .NET» |
| Проект не открывается в старой Visual Studio | Создайте проект «Приложение Windows Forms» и добавьте в него файлы `.cs` (кроме `.csproj`) |
